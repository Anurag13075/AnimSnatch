How to install (Developer Mode)

1

Download & Extract

Download the AnimSnatch.zip file and extract the folder to your computer.

2

Open Extensions Page

Open Google Chrome and navigate to chrome://extensions in your address bar.

3

Enable Developer Mode

Toggle the Developer mode switch in the top right corner of the page.

4

Load Unpacked

Click the Load unpacked button and select the AnimSnatch folder you extracted in step 1. Pin the extension and you're ready to go!
