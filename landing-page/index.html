Digging through DevTools is a waste of time.

When you see a beautifully designed component or a complex cubic-bezier animation on a website, figuring out how it's built manually is painful. You have to inspect the element, track down the exact CSS rules overriding each other, find the keyframes in a separate tab, and rewrite the HTML.

AnimSnatch automates this. It deeply clones the DOM node you click, scans the page's stylesheets for the exact CSS rules applying to that node, and packages it perfectly for your clipboard.

  return (
    <div className="snatched-element">

      <p className="desc">Cloned directly from the DOM.</p>
    </div>
  );
}

Everything you need to extract UI

React Component Formatting

Automatically converts standard HTML `class` and `for` attributes into React-compliant `className` and `htmlFor`. Pastes directly into your JSX files.

Keyframe Resolution

Extracts the exact `@keyframes` rule from the CSS Object Model (CSSOM). No more guessing cubic-bezier easing values or transform origins.

Hidden Asset Extraction

Can't right-click an image? AnimSnatch digs into the computed styles to find background-images, inline SVGs, and hidden <img> tags and downloads them directly.

Get Started in 60 Seconds

AnimSnatch is currently distributed as an unpacked extension for developers.

1

Download & Extract

Download the AnimSnatch.zip file and extract the folder to a permanent location on your hard drive.

2

Open Extensions Page

Open Google Chrome, type chrome://extensions into your address bar, and hit Enter.

3

Enable Developer Mode

Toggle the Developer mode switch located in the top right corner of the Chrome extensions page.

4

Load Unpacked

Click the "Load unpacked" button and select the AnimSnatch folder you extracted in Step 1. Pin the extension to your toolbar, and you're done.

Frequently Asked Questions

Does this work with Tailwind CSS?

If a website uses Tailwind, AnimSnatch will copy the exact Tailwind utility classes applied to the DOM node because they exist in the `class` attribute. However, if they use purged/custom Tailwind configs, you will also get the raw computed CSS fallback extracted.

Why isn't this in the Chrome Web Store?

AnimSnatch is currently in developer preview and is completely free and open-source. Distributing it as a `.zip` allows us to bypass the Chrome Web Store review times and $5 developer fee while we iterate rapidly on new features like CodePen export.

Does it extract JavaScript functionality?

No. AnimSnatch is strictly a design extraction tool. It extracts the structural DOM (HTML/JSX) and the visual styling (CSS/Animations/Assets). It does not extract attached event listeners or React state logic.
